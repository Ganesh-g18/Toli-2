# Indian vehicle model catalogue

Researched 14 October 2026: 507 model-family entries across 43 brands, including all 35 brand suggestions and eight manually entered legacy brands. This is broad practical coverage, not an exhaustive registration database or a workshop service commitment.

## Method and boundaries

Official Indian manufacturer ranges/brochures/owner resources were prioritized where accessible, with Indian automotive current and discontinued catalogues as cross-checks and legacy coverage. The table links the research sources for every brand. Families combine generations, fuel types and trims; EV models with distinct customer-facing names remain separate. We excluded future-only announcements, concept names, foreign-market-only entries and unsupported catalogue placeholders rather than copying entire category pages. Historic model families stay available even when their brand is no longer in the current-market suggestion list. Brand identifiers match the existing selector; manual entry permits omitted models and brands.

No year, engine, fuel or variant dependency is introduced. Neither list membership nor a non-empty model is required. Free-text custom values remain valid; brand changes clear the model to avoid stale associations. No live API is called.

## Source interpretation

CarWale pages contain upcoming/global/import placeholders alongside Indian current and discontinued cars. The selected families were reviewed, not generated from every link. Nameplate normalization removes source year ranges and introductory labels (for example Old Generation), and preserves readable names (Grand i10 NIOS, City e:HEV, ë-C3). Current and older models intentionally share one alphabetical list because this is a service enquiry. Missing brand/model combinations always allow free text.

Legacy additions Ford, Chevrolet, Fiat, Jaguar, Datsun, Mitsubishi, Hindustan Motors and Abarth are model lookup keys only: the current Indian-market brand suggestion list remains unchanged. For example, typing Ford provides EcoSport/Endeavour/Figo-era choices; typing Chevrolet provides Beat/Spark/Tavera-era choices.

Review source ranges during future updates. Manufacturer pages can redirect or retire legacy material; dated sources establish presence, not an assurance that every model remains on sale.
