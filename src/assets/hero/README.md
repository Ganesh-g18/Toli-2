# Approved hero campaign artwork

The active hero uses the original transparent gunmetal sports-car graphic in responsive 960px and 1440px WebP variants. The single picture element uses high fetch priority and asynchronous decoding. Original framing and restrained floor illumination are restored.

It is an image presentation, not a configurator. There is no hero scene dock, hidden WebGL canvas, vehicle label, diagnostic caption, technical grid, rotation or inspection UI. Below-fold sections retain the shared renderer and their SVG fallback.

See CAMPAIGN-ASSET.md for original provenance. Older luxury-GT derivatives and previous hero experiments remain unused. Do not substitute another car or reactivate legacy vehicle implementations.
